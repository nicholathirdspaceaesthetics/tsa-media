# Club Pilates Sippy Downs design studio

Renders @clubpilatessippy creatives from JSON specs (`render.py`). Read STYLE.md (the design kit) and PLAYBOOK.md (how scheduled runs publish).
Logo and mandala files were taken from the 2026 Club Pilates Brand Book artwork. Photos are not stored here: they live on the approvals page as lib/<n>.jpg.
Everything under cp/ is self-contained so it can be handed to a new studio owner as its own repo.
